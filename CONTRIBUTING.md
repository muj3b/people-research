# Contributing

Keep it free, no-key, and honest.

- New routes must work with no login and no API key, or be labelled as a browser/login fallback, never as no-login.
- Test on a real public URL and record the command, result, and date in SKILL.md. Do not claim a route from docs alone; mark it docs-claimed until it is live-tested.
- Never add credentials, session tokens, private URLs, or paid API keys. Never add a CAPTCHA, paywall, or access-control bypass.
- If a route stops working, keep the old note with its date and add the new status, so the history stays auditable.
- Keep README changes short and KISS: one benchmark row, one matrix row, one caveat line, unless the change is bigger.
